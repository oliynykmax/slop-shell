# slop-shell

A Unix shell where nothing is real. Every response is generated by an LLM — no filesystem, no processes, no kernel, no I/O. Commands "work" because the model hallucinates plausible output and remembers it for the rest of the session.

Useful for: impressing nobody, debugging your patience, and watching an AI maintain a fake `cwd` across `cd /` and `cd ~`.

## Demo

```
$ slop-shell
Welcome to the slop shell
kort@slopbox:~$ pwd
/home/kort
kort@slopbox:~$ ls
Desktop  Documents  Downloads  Music  Pictures  projects
kort@slopbox:~$ cat .bashrc | head -3
# ~/.bashrc: executed by bash(1) for non-login shells.
export PATH="$HOME/.local/bin:$PATH"
[ -r "$HOME/.profile" ] && . "$HOME/.profile"
kort@slopbox:~$ mkdir ~/projects/void && cd ~/projects/void
kort@slopbox:~/projects/void$ touch hello
kort@slopbox:~/projects/void$ ls
hello
kort@slopbox:~/projects/void$ rm hello
kort@slopbox:~/projects/void$ ls
kort@slopbox:~/projects/void$ exit
logout
```

Everything above is invented. `ls` didn't run; `pwd` didn't read a kernel. The model is just roleplaying a shell and tracking the conversation.

## Install

```bash
go install github.com/oliynykmax/slop-shell@latest
```

Or from source:

```bash
git clone https://github.com/oliynykmax/slop-shell.git
cd slop-shell
go build -o slop-shell .
./slop-shell
```

## Configuration

Get a key from [DeepSeek](https://platform.deepseek.com/) and set it:

```bash
export DEEPSEEK_API_KEY="sk-..."
```

Or drop a `.env` file in the directory you launch from (or `~/.config/slop-shell/.env`):

```
DEEPSEEK_API_KEY=sk-...
```

`GEMINI_API_KEY` is also accepted as a legacy fallback. The shell probes `deepseek-v4-flash` at startup and exits if the key is rejected.

## Features

- **Streaming** — tokens print as they arrive, line-by-line. Disable with `--no-stream`.
- **Local colorizer** — `ls`, `grep`, and friends get ANSI colors applied by a regex pass over the streamed output, so the model never has to emit escape codes. Disable with `--no-color`.
- **Persistent history** — arrow keys, `Ctrl+R` reverse search, saved to `~/.slop_history`.
- **AI tab completion** — `Tab` asks the model for completions based on what you've typed and your recent history. Cached so rapid presses don't hammer the API.
- **sudo** — password prompt is shown for any `sudo …`. Any password is accepted. `sudo su` / `sudo -i` flips to a `root@slopbox:~#` prompt until you `exit`.
- **Ctrl+C** — cancels an in-flight request without leaving the shell. The readline handler still cancels the current line as usual.
- **MOTD** — one magenta line on startup. Suppress with `--no-motd`.

## Flags

| Flag | Description |
|------|-------------|
| `--no-stream` | Wait for the full response before printing |
| `--no-motd` | Skip the welcome line |
| `--no-color` | Skip the local colorizer pass |

## Caveats

- The model is sampled at temperature 0.7, so the same input gives different output across runs.
- The model tracks state in its context window, not in any real data structure. Long sessions drift; `cd` may not stick if you give it a hard prompt.
- The session-level conversation history is capped at 256 messages and re-sent every turn. DeepSeek V4 has roughly a 1M-token context window, so this cap is a sanity limit, not a budget.
- Anything you "do" in the shell is forgotten when you exit.

## Architecture

Three files in `package main`:

- **`main.go`** — readline loop, MOTD, sudo prompt, tab-completion wiring, `SlopShell` orchestration, system-prompt construction, anti-injection shield on user input.
- **`provider.go`** — `Provider` interface with the `DeepSeek` implementation. Retries 429/503 with exponential backoff, SSE streaming parser, `Probe` validates each model at startup.
- **`colorize.go`** — local regex-based ANSI colorizer applied to streamed output. `colorize_test.go` covers the colorizer, the prompt-line detector (NBSP/tab edge cases), and the tab-completion LRU.

The simulated environment is `slopbox` running Ubuntu 24.04. The hostname is hardcoded in several places (`buildSystemPrompt`, the prompt regex, `isPromptLine`, the initial prompt string) — search for `slopbox` before changing it.
