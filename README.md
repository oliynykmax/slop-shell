# 🧠 slop-shell

A fully hallucinated Unix shell powered by AI. Nothing is real.

`slop-shell` is a fake terminal that looks and feels like a real bash shell, but every single response is generated by an AI model. There is no filesystem. There are no processes. There is no kernel. It's all vibes.

The AI maintains a consistent virtual environment — it tracks your current directory, remembers files you "created", simulates commands, and responds with realistic terminal output. Pipe commands, chain them with `&&`, use environment variables — it all "works".

## Install

### One-liner

```bash
go install github.com/oliynykmax/slop-shell@latest && ln -sf "$(go env GOPATH)/bin/slop-shell" ~/.local/bin/slop-shell
```

### From source

```bash
git clone https://github.com/oliynykmax/slop-shell.git
cd slop-shell
go build -o slop-shell .
cp slop-shell ~/.local/bin/
```

## Configuration

Set your Gemini API key:

```bash
export GEMINI_API_KEY="your-key-here"
```

Or create a `.env` file in the directory where you run `slop-shell`:

```
GEMINI_API_KEY=your-key-here
```

The shell automatically picks the best available Gemini model (tries newest first).

## What works

- `ls`, `cat`, `grep`, `find`, `ps`, `top`, `df`, `du` — all hallucinated
- `cd` — tracks working directory across commands
- Pipes (`|`), chaining (`&&`, `||`, `;`)
- Environment variables (`export`, `$VAR`)
- Redirects (`>`, `>>`)
- Realistic error messages for invalid commands
- Persistent state within a session — create a file, it "exists" later
- `Ctrl+C` to interrupt

## What doesn't work

- Actually executing anything
- Talking to real hardware
- Being deterministic
- Giving you accurate information about... anything

## Requirements

- Go 1.21+
- A [Gemini API key](https://aistudio.google.com/apikey)
